# Reynalds OS Agent Entry Point

This file is the machine-discoverable entry point for AI agents and developers working in Reynalds OS.

## Mandatory First Action

Before recommending, creating, modifying, staging, committing, or pushing repository work, run:

```bash
pnpm ai:preflight
```

## Required Inspection

After running the preflight:

1. Read `START_HERE.md`.
2. Follow its required reading order.
3. Read the applicable global Brain documents.
4. Identify the active company or platform domain.
5. Read that domain's Brain and governing canonical sources.
6. Search the repository for existing implementations.
7. Verify the repository path, remote, branch, working tree, and proposed target files.
8. State what was inspected and what files are proposed for modification.
9. Wait for explicit user approval before meaningful implementation.

## Operating Rules

- The repository is the source of truth. Conversation memory is not.
- Recover before reinventing.
- Extend before creating.
- Search first. Extend second. Create last.
- Do not modify, stage, commit, or push unrelated work.
- Use the smallest working slice.
- Validate before committing.
- Update continuity documentation when required by the governing standards.
- Do not claim completion without repository evidence.
