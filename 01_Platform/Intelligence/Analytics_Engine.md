# Analytics Engine

## Purpose

Compute platform metrics from shared objects instead of relying on static dashboard values.

## Metric Sources

- Objects
- Object statuses
- Health scores
- Timeline events
- Workflow stages
- Automation rules
- Invoices and payments
- Tasks and deadlines
- Customer success records

## Core Analytics

### Operations
- Active work
- Overdue work
- Work by owner
- Average completion time
- Bottlenecks

### Transactions
- Active transactions
- Transactions by health
- Closings this week
- Average days to close
- Exceptions per file

### Finance
- Revenue this month
- Outstanding invoices
- Revenue by service
- Forecasted revenue
- Average revenue per client

### Customer Success
- Review requests
- Testimonials
- Referral opportunities
- Relationship health
- Repeat clients

### Repository
- Certified objects
- Documentation coverage
- Automation coverage
- Repository maturity
- Change velocity

## Rule

A metric must identify the object fields and calculations that created it.
