# AI Copilot Specification

## Purpose

Create an AI layer that can reason over ROS context and assist with decision-making, drafting, prioritization, and explanation.

## Context Sources

- Shared objects
- Relationship graph
- Workflow definitions
- Universal timeline
- Automation rules
- SOPs
- Decision Playbooks
- Templates
- KPIs
- Permissions
- Repository standards

## Copilot Capabilities

### Explain
- Why is this file critical?
- What is blocking this closing?
- Why did this transaction turn red?

### Prioritize
- What should I work on next?
- Which clients need follow-up?
- Which deadlines are most important today?

### Draft
- Draft client update
- Draft review request
- Draft missing information request
- Draft broker update

### Recommend
- Recommend next action
- Recommend escalation
- Recommend workflow improvement
- Recommend repository update

### Execute With Review
- Create task
- Prepare invoice
- Queue automation
- Start workflow
- Create timeline note

## AI Grounding Rule

Every Copilot answer must be explainable through referenced ROS objects, fields, events, workflows, rules, or repository content.
