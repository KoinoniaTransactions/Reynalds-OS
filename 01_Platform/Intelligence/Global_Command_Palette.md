# Global Command Palette

## Purpose

Provide one universal interface for navigating, searching, creating, and executing guided actions across ROS.

## Supported Command Types

- Open object
- Search repository
- Create object
- Start workflow
- Generate report
- Draft communication
- Assign task
- Run automation
- Show priority list
- Display timeline
- Open related module

## Example Commands

- Open Smith Transaction
- Create invoice for Sarah Johnson
- Assign Meadow View Showing
- Show overdue tasks
- Generate daily briefing
- Find inspection objection playbook
- Draft closing reminder
- Open Workflow WF-000001

## Command Rule

A command should either navigate, create, update, explain, or summarize.
