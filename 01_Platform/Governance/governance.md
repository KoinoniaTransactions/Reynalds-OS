# ROS Governance

Single source of truth: ROS Core Repository.

Rules:
1. No duplicate sources of truth.
2. Every approved change receives a ROS change ID.
3. Every production item is represented as an object.
4. Every object must include identity, purpose, relationships, operations, intelligence, and archive fields.
5. Spreadsheets, dashboards, websites, and documents are interfaces or exports, not the Brain itself.
6. Future work is implementation-first unless a genuine architecture gap is found.
