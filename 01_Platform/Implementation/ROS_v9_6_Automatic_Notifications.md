# ROS-0081 — Automatic Notification Generation

## Purpose

Create the first automatic notification generation behavior in ROS.

## Added

- Notification generation API.
- Critical object alerts.
- High-priority task alerts.
- Pending invoice alerts.
- Duplicate prevention.
- Timeline events for auto-generated notifications.
- Generate Alerts action in Notification Center.

## Platform Rule

Automations should surface important work without hiding the reason the alert exists.
