# ROS-0082 — Workflow Automation Engine MVP

## Purpose

Create the first production Workflow Automation Engine foundation.

## Added

- Workflow API.
- Workflow run API.
- Workflow start endpoint.
- Workflow page.
- Starter workflow seed action.
- Workflow stages and steps display.
- Timeline event on workflow start.

## Major Release Reason

ROS v10.0 shifts the platform from module-based MVPs into workflow-driven operations.

## Platform Rule

Workflow definitions should explain how work moves. Workflow runs should record how work actually moved.
