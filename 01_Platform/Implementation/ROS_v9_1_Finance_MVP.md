# ROS-0076 — Finance MVP

## Purpose

Build the first production Finance module using invoices linked to shared ROS objects.

## Added

- Finance page.
- Invoice API.
- Invoice status update route.
- Create invoice UI.
- Mark paid action.
- Revenue metrics.
- Timeline events for invoice creation/payment.

## Platform Rule

Every dollar should trace back to client, service/package, invoice, payment, and related work object where applicable.
