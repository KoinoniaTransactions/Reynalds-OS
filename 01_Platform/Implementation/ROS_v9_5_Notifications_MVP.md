# ROS-0080 — Notifications MVP

## Purpose

Build the first production Notification Center using persisted notification records.

## Added

- Notifications page.
- Notification API list/create.
- Notification update route.
- Level/status filters.
- Search.
- Mark read action.
- Resolve action.
- Related object context.
- Timeline events for related notifications.

## Platform Rule

Notifications should reduce uncertainty, not create noise.
