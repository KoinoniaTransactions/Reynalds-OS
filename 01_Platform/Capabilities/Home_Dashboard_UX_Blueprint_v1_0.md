# ROS-0041 — Home Dashboard UX Blueprint v1.0

## Mission

The Home Dashboard should answer one question: What should I work on right now?

## Layout

Header:
- Global Search
- New button
- Quick Actions
- Notifications
- User Profile
- AI Command Bar

Main sections:
- Priority Panel
- KPI Cards
- My Work Queue
- Calendar & Closings
- Revenue Snapshot
- Recent Activity
- AI Recommendations

## Priority Panel

The highest-value dashboard section. Every item is ranked by urgency and impact.

Examples:
- Closing tomorrow
- Inspection deadline today
- Draft waiting on approval
- Showing feedback overdue
- Review request ready

## KPI Cards

- Active Transactions
- Draft Requests
- Showings Scheduled
- Revenue This Month
- Tasks Due Today
- Customer Satisfaction

## My Work Queue

Grouped by:
- Due Now
- Today
- Waiting on Client
- Waiting on Vendor
- QA Review
- Follow-Up
- Completed Today

## Calendar

Show only actionable calendar items:
- Closings
- Inspections
- Showings
- Draft deadlines
- Follow-ups

## Revenue Snapshot

- This Month
- This Quarter
- Outstanding Invoices
- Forecasted Revenue
- Revenue by Service

## AI Recommendations

Examples:
- Three transactions need follow-up today.
- Coordinator capacity is reaching 90% next week.
- Five clients are ready for review requests.
- Inspection objections are trending higher this month.

Every recommendation links to supporting data.
