# Workflow Engine

## Purpose

Make workflows reusable, measurable, and eventually executable.

## Workflow Definition

Every workflow includes:

- Workflow ID
- Name
- Trigger
- Stages
- Tasks
- Required Inputs
- Outputs
- Owner
- SLA / Timing Rules
- Decision Points
- Exception Paths
- Completion Criteria
- Related Objects
- KPI Links
- Automation Links

## Core Workflows

- Relationship Qualification
- Client Onboarding
- Transaction Intake
- Transaction Management
- Contract Drafting
- Showing Coverage
- Invoice Creation
- Payment Tracking
- Customer Success Handoff
- Review Request
- Referral Follow-Up

## Workflow Rule

An SOP explains how work is done. A workflow defines how work moves.
