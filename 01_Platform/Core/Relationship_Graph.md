# Relationship Graph

## Purpose

Track how every object connects to every other object.

## Example

Sarah Johnson
- Brokerage: Parker Realty Group
- Transactions: Smith, Johnson, Carter
- Package: Transaction Coordination Plus
- Invoices: INV-1007, INV-1012
- Communications: Status updates, closing reminders
- Customer Success: Review request, referral opportunity

## Relationship Types

- Owns
- Belongs To
- References
- Depends On
- Triggers
- Blocks
- Generates
- Completes
- Archives
- Replaces

## Rule

Users should navigate through relationships, not folders.
