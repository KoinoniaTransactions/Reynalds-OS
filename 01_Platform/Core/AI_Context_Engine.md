# AI Context Engine

## Purpose

Give AI access to structured context so recommendations are grounded in system data.

## Context Sources

- Object fields
- Relationship graph
- Timeline events
- Workflows
- SOPs
- Decision Playbooks
- Communication history
- Dashboard metrics
- Exceptions
- Deadlines
- Repository objects

## AI Use Cases

- What should I work on next?
- What is blocking this closing?
- Why is this file high risk?
- Draft the next client update.
- Which clients need follow-up?
- Which workflows are creating bottlenecks?
- Which repository objects need improvement?

## AI Grounding Rule

Every AI recommendation must be traceable to specific objects, fields, events, or rules.
