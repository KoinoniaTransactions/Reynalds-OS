# Universal Timeline

## Purpose

Create one chronological history for every meaningful event across ROS.

## Timeline Events

- Object created
- Status changed
- Task completed
- Deadline added
- Communication sent
- Document received
- QA review completed
- Exception opened
- Exception resolved
- Invoice sent
- Payment received
- Review requested
- Referral created
- Repository updated

## Event Fields

- Event ID
- Timestamp
- Actor
- Event Type
- Related Object
- Summary
- Source Module
- Previous Value
- New Value
- Notes

## Rule

If an action matters later, it belongs on the timeline.
