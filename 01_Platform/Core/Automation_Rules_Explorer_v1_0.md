# ROS-0061 — Automation Rules Explorer v1.0

## Purpose

Add an Automation Rules Explorer to the ROS interactive application shell.

## Files Added

- `08_Data/sample_automation_rules.json`
- `08_Data/sample_automation_rules.csv`

## Included Features

- Automation Rules module.
- Rule table.
- Status filters.
- Rule detail panel.
- Trigger/condition/action visibility.
- Human review indicator.
- Dashboard impact.
- Simulated rule-run actions.

## Core Function

Automation Rules Explorer makes platform automation observable before it becomes executable.

## Automation Rule

Automation should increase confidence, not reduce visibility.
