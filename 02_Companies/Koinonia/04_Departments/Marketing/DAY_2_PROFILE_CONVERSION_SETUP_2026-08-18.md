**Social profile -> tracked Koinonia consultation page -> one Relationship record.**

# Conversion Destination Rules

## Profile visitor

Send to:

`/contact#schedule-consultation`

Reason:

A profile visitor has already shown enough intent to benefit from a direct next step.

## General educational post

Send to:

- `/` for broad category/brand education
- `/services` when the post is about the five-service system
- `/contact#schedule-consultation` when the post is an explicit service invitation
- `/referrals` only for dedicated Referral Partner content

Do not send every post to the Contact page.

## Referral content

Dedicated referral content should route to:

`/referrals`

Keep service and referral conversion paths conceptually separate.

## Brokerage leader content/outreach

Primary conversion is not a generic web form.

Use:

- direct email reply
- phone conversation
- consultation when useful

The website supports credibility; the relationship is the conversion path.

# First-Touch Attribution Rule

The website launch-readiness implementation preserves the first attributable source for the browser session and passes it into the Koinonia consultation intake.

For a new Relationship record, the intended result is conceptually:

- Source: Social Media
- Source detail: Instagram / Facebook / TikTok + medium/content
- First-touch channel: platform name
- Campaign: UTM campaign
- Referrer: source page/site when available

If the person already exists as a Koinonia Relationship, later consultation activity must not erase the earlier first-touch acquisition source.
