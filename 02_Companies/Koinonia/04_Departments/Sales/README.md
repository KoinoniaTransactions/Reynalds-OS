# Sales Operating System

Mission: Create a predictable, measurable, repeatable process that turns strangers into long-term Koinonia advocates.

Lifecycle:

Awareness → Interest → Lead → Qualified Lead → Consultation → Proposal → Client → Active Engagement → Successful Delivery → Advocate → Referral.

## Canonical Consultation System

The consultation stage is governed by:

`BRAIN/KOINONIA_CONSULTATION_INTERVIEW_SYSTEM.md`

That file is the source of truth for the 20–30 minute Koinonia consultation/interview structure, diagnostic sequence, reveal order, pricing timing, objection logic, first-engagement close, consultation outcome, and follow-up discipline.

Do not create competing consultation scripts inside Sales, Marketing, presentations, campaign documents, or training material.

Service claims, scope, packages, pricing, onboarding, and professional boundaries remain governed by their existing canonical Koinonia business objects and current approved processes.

## Consultation Execution Toolkit

The practical execution layer for the canonical consultation system lives in:

`02_Companies/Koinonia/04_Departments/Sales/Consultation/`

Toolkit contents:

- `Consultation/README.md` — toolkit governance and non-duplication rules.
- `Consultation/KOINONIA_CONSULTATION_FIELD_GUIDE.md` — compact live conversation aid.
- `Consultation/KOINONIA_CONSULTATION_SCORECARD.md` — consultation notes, diagnosis, fit, decision, and next-action record.
- `Consultation/KOINONIA_POST_CONSULTATION_FOLLOW_UP_SYSTEM.md` — outcome-based follow-up templates and cadence.
- `Consultation/KOINONIA_CONSULTATION_PRESENTATION_SYSTEM.md` — modular presentation, leave-behind, pricing-card, and brokerage-scope collateral logic.
- `Consultation/KOINONIA_CONSULTATION_ROLE_PLAY_CERTIFICATION.md` — role-play scenarios, evaluation, objection drills, and consultation-readiness standard.

These files operationalize and train the Brain source. They do not supersede it.

When consultation logic changes, update the canonical Brain source first and then bring the execution toolkit back into alignment.
