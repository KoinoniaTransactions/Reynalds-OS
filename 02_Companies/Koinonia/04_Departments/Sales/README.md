# Sales Operating System

Mission: Create a predictable, measurable, repeatable process that turns strangers into long-term Koinonia advocates.

Lifecycle:

Awareness → Interest → Lead → Qualified Lead → Consultation → Proposal → Client → Active Engagement → Successful Delivery → Advocate → Referral.

## Shared Relationship Learning Record

Sales uses the same relationship record governed by:

`02_Companies/Koinonia/04_Departments/Marketing/MARKETING_LEARNING_RELATIONSHIP_CAPTURE_SYSTEM.md`

Do not create a separate competing Sales contact history when Marketing, Operations, and Customer Success are tracking the same professional relationship.

Sales owns the relationship record fields related to:

- qualification
- consultation diagnosis
- desired outcome
- current workaround
- keep-client vs refer-client path
- service initially requested
- service/path recommended
- diagnosis rationale
- prospect objections or hesitation
- proposal/quote status
- first-engagement conversion
- no-sale/lost reason
- next agreed action and follow-up timing

Preserve useful prospect language instead of translating every conversation only into internal service terminology.

## Consultation Principle

**Diagnose first. Prescribe second. Present third.**

Recommendation formula:

**Because you told me [problem] is causing [consequence], I would start with [service] so we can [specific desired outcome].**

Use the smallest sufficient engagement when possible.

Canonical relationship principle:

**The first engagement should earn the second engagement.**
