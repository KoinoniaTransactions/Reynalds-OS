# Sales Operating System

Mission: Create a predictable, measurable, repeatable process that turns strangers into long-term Koinonia advocates.

Lifecycle:

Awareness → Interest → Lead → Qualified Lead → Consultation → Proposal → Client → Active Engagement → Successful Delivery → Advocate → Referral.

## Canonical Consultation System

The consultation stage is governed by:

`BRAIN/KOINONIA_CONSULTATION_INTERVIEW_SYSTEM.md`

That file is the source of truth for the 20–30 minute Koinonia consultation/interview structure, diagnostic sequence, reveal order, pricing timing, and first-engagement close as those sections are approved.

Do not create competing consultation scripts inside Sales, Marketing, presentations, or campaign documents.

Service claims, scope, packages, pricing, and professional boundaries remain governed by their existing canonical Koinonia business objects.
