# Customer Success

Mission: Build lasting professional relationships that create trust, repeat business, referrals, and long-term partnerships.

Lifecycle:

Transaction Closed → Successful Handoff → Client Satisfaction → Review/Testimonial → Relationship Nurture → Repeat Business → Referral → Advocate.

## Shared Relationship Learning Record

Customer Success continues the same relationship history governed by:

`02_Companies/Koinonia/04_Departments/Marketing/MARKETING_LEARNING_RELATIONSHIP_CAPTURE_SYSTEM.md`

Do not create a disconnected post-service client record when Marketing, Sales, and Operations are already tracking the same professional relationship.

Customer Success owns relationship-learning fields related to:

- satisfaction and client feedback
- repeat engagement
- services used over time
- cross-service adoption
- time from first engagement to second engagement
- next logical adjacent support
- relationship nurture
- review/testimonial status
- brokerage/team introductions
- professional referrals
- advocate status
- last meaningful interaction
- next follow-up/nurture date
- long-term relationship value

Canonical relationship principle:

**The first engagement should earn the second engagement.**

Customer Success should help determine whether that actually happened, why it happened, and what Koinonia should learn from the relationship without forcing an upsell.
