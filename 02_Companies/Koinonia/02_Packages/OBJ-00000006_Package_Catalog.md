# OBJ-00000006 Package Catalog

Class: Master Object
Type: Package Catalog
Module: Koinonia
Status: Active
Version: 1.0
Owner: Koinonia
Memory Level: Foundational

Purpose:
The Package Catalog is the single source of truth for how Koinonia services are bundled, sold, billed, delivered, and tracked.

Approved packages:
- OBJ-00000007 Transaction Coordination Plus
- OBJ-00000008 Realtor Support Plus
- OBJ-00000009 Pay-at-Closing Coordination

Rules:
1. Every client must be assigned a package or custom support plan.
2. Every package must activate specific services.
3. Every package must have a billing rule.
4. Custom pricing must be logged as a package variation.
