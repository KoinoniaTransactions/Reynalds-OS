## Purpose

The Package Catalog is the single source of truth for **what a Realtor can hire Koinonia to provide as a commercial product**.

Service objects define capabilities. This catalog keeps the actual buying decisions intentionally small and simple.

## Current Commercial Product Set

- **OBJ-00000019 — Transaction Management**  
  One managed transaction lifecycle. Current working price governed by OBJ-00000024.

- **OBJ-00000020 — Hand Us the Listing**  
  One managed listing-side lifecycle through accepted-offer handoff. Current working price governed by OBJ-00000025.

- **OBJ-00000021 — Licensed Field Coverage**  
  Approved in-person property/client assignments, including the professional open-house assignment type. Current working price governed by OBJ-00000026.

- **OBJ-00000022 — Marketing Management**  
  Recurring managed Realtor marketing. Current working price governed by OBJ-00000027.

- **OBJ-00000023 — Koinonia Partnership**  
  Recurring managed marketing plus agreed CRM/business-operations support. Current working price governed by OBJ-00000028.

## Custom Project Path

A defined need that does not fit a standard product may be scoped as one custom project/request under OBJ-00000029. “Ask Koinonia” is an intake path, not a sixth named core product.

## Rules

1. Every client engagement must map to a current product, an approved custom project, or an explicitly documented variation.
2. Every current product must map to one or more service capability objects.
3. Every quoted commercial product must have an applicable active/current pricing rule.
4. Do not create a new package merely because a new task/capability exists.
5. A new package should exist only when it represents a distinct customer buying decision and outcome.
6. Outside expenses are governed separately from Koinonia service fees unless a written package explicitly states otherwise.
7. Current product objects marked Pre-Launch require fulfillment/operational readiness and applicable compliance gates before universal public availability is claimed.
