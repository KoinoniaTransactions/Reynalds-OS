# Koinonia Print-Ready Branded Material Sources

Status: Working Print/Digital Source v1  
Owner: Koinonia Transactions  
Purpose: Provide reusable branded material source files for real Koinonia business use and Google Business Profile video verification.

## Files

- `index.html` — quick preview page linking all materials.
- `koinonia_materials.css` — shared print/digital visual system.
- `business_card.html` — two-sided business card source.
- `service_sheet.html` — one-page service sheet source.
- `invoice_estimate.html` — invoice/estimate template source.
- `one_page_flyer.html` — one-page brochure/flyer source.

## How To Use

Open any `.html` file in a browser.

For Google Business verification:

- Show the files digitally on a monitor, or
- Print the pages and place them neatly on the desk.

For PDF export:

- Open the file in a browser.
- Use Print.
- Choose Save as PDF.
- Use default margins unless the print shop requests otherwise.
- For the business card, export front and back separately if the printer requires individual files.
