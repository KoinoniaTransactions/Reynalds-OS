# OBJ-RB-000000 — Object Catalog

## Purpose

The Object Catalog is the canonical index of Reynalds Brothers business objects.

Every Reynalds Brothers object should be listed here before it is implemented in software, databases, APIs, dashboards, or AI workflows.

---

## Object Namespace

Reynalds Brothers objects use the prefix:

`OBJ-RB-`

## Governance

Objects listed here belong only to the Reynalds Brothers company domain.

They must remain separate from Koinonia objects and platform-level Reynalds OS objects.

Platform capabilities may consume these objects, but Reynalds OS platform logic must not own Reynalds Brothers business logic.
