# Reynalds Brothers Brain

## Purpose

The Reynalds Brothers Brain preserves the business-specific operating knowledge for Reynalds Brothers inside Reynalds OS.

This domain is separate from Koinonia. Reynalds Brothers is a managed company domain, not a company owned by the user.

## Canonical Rule

Reynalds Brothers business logic belongs under:

`02_Companies/Reynalds_Brothers/`

Platform logic belongs under:

`01_Platform/`

Global Reynalds OS governance belongs under:

`BRAIN/`

## Current Status

Initialized as a first-class company domain inside Reynalds OS.

2026-07-29 update: first app implementation started as a dedicated company workspace at `/reynalds-brothers`, backed by the Reynalds Brothers Work Item engine and a dedicated company API.

## Primary Object

The first canonical object is:

`00_Master_Objects/OBJ-RB-000001_Work_Item.md`

## Operating Principle

Reynalds Brothers organizes around Work Items, not spreadsheets, folders, or external systems.

The operating question for every app view should be:

Is this work item ready, moving, completed, documented, and billable?
