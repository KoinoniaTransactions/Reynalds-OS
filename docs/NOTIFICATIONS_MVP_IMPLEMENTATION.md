# ROS v9.5 — Notifications MVP

## Added

- `/notifications` page.
- Notification list/create API.
- Notification update route.
- Create notification UI.
- Level and status filters.
- Client-side search.
- Mark read action.
- Resolve action.
- Related object context.
- Timeline event creation when related notifications are created/updated/resolved.

## Current Limitations

- Notifications are manual, not automated yet.
- No due-date reminder engine yet.
- No user-specific inbox filtering yet.
- Dashboard notification widget is not added yet.

## Next Recommended Work

- Add automatic notifications from critical objects, open tasks, and pending invoices.
- Add server-side search.
- Add task due dates and owner assignment.
