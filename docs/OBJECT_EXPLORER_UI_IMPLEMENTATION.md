# ROS v8.4 — Database-Backed Object Explorer UI

## Added

- `/objects` page.
- Client-side Object Explorer component.
- API-backed object list.
- Object type/status/health filters.
- Object detail panel.
- Related object display.
- Timeline event display.
- Archive object action.
- Design system styles for tables, filters, and split layout.

## Current Limitations

- Search box is placeholder.
- Create object form is not implemented yet.
- Filtering is exact-match through API query params.
- Auth is still mock-auth scaffold.
