# Koinonia Body / Card Modernization Notes

Status: Active visual direction
Date: 2026-07-13

## Purpose

The public Koinonia site should feel modern, calm, premium, and portal-ready below the hero sections.

## Direction

- Keep copy intact unless explicitly approved
- Avoid rebuilding page structure unless required
- Use the design system to modernize section rhythm first
- Make cards feel less flat and less template-like
- Use subtle layering, softer premium surfaces, and restrained motion
- Keep the light and airy brand direction
- Avoid dark/heavy redesigns outside intentional band sections

## Current Pass

The first body modernization pass updates global section, card, button, band, pricing, and consultation-card styling.

The next pass can selectively update page assemblies if visual review shows the layout still feels too repetitive.
