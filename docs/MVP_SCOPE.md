# MVP Scope

## Included

- Login
- Workspace
- Object Engine
- Relationship Graph
- Object Explorer
- CRM
- Transactions
- Tasks
- Timeline
- Operations Queue
- Basic Finance
- Knowledge metadata
- Dashboard metrics
- Read-only Copilot

## Excluded From First MVP

- Destructive automations
- Complex AI write actions
- Multi-brand billing
- Mobile app
- Deep integrations
- Advanced reporting warehouse

## MVP Rule

Build trusted manual operations before advanced automation.
