# ROS v9.3 — Knowledge MVP

## Added

- `/knowledge` page.
- Database-backed Knowledge Center.
- Service, Workflow, Template, Decision Playbook, and SOP object loading.
- Search and type filters.
- Knowledge detail panel.
- Metadata display.
- Related object display.
- Timeline display.
- Seed Service action for creating a Business Operations Support Service object.

## Current Limitations

- Knowledge item creation is simplified through seed action/Object Explorer.
- Full text search is client-side.
- No markdown/document rendering yet.
- No repository import pipeline yet.

## Next Recommended Work

- Add server-side search.
- Add Knowledge item create/edit form.
- Add repository import from certified object files.
