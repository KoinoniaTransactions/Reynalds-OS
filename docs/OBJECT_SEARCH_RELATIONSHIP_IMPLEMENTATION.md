# ROS v8.7 — Object Search & Relationship UI

## Added

- Client-side object search.
- Status dropdown filter.
- Health dropdown filter.
- Object type dropdowns for create/edit forms.
- Relationship creation form.
- Relationship creation through `POST /api/relationships`.
- Detail refresh after relationship creation.

## Current Limitations

- Relationship deletion is not implemented.
- Search is client-side only.
- Relationship types are free text.
- No relationship timeline event yet.

## Next Recommended Work

- Add relationship timeline events.
- Add relationship delete action.
- Build CRM MVP using object model.
