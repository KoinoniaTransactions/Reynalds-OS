# Properties Inquiry

## Purpose

Reusable inquiry block for Koinonia Properties owner, tenant, maintenance, vendor, and rental-analysis paths.

## Used By

- `/properties`
- `/properties/owners`
- `/properties/tenants`
- `/properties/rental-analysis`
- `/properties/apply`
- `/properties/maintenance`
- `/properties/vendors`

## Governance

Uses email handoff instead of collecting sensitive owner, tenant, applicant, or maintenance data directly on the website until privacy, portal, screening, and operating policies are finalized.
