# Reynalds OS Brain

## Purpose

This folder is the authoritative operating brain for Reynalds OS.

It exists so future development does not depend on memory, scattered chat history, or old app shell versions.

## Core Rule

When there is a conflict between an old prototype and this Brain, this Brain is the source of truth.
