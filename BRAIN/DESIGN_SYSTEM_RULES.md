# Design System Rules

## Brand Direction

Koinonia ERP uses a professional executive style:

- Cream background.
- Black sidebar / strong contrast.
- Gold accent.
- Clean cards.
- Rounded surfaces.
- Clear hierarchy.
- Minimal clutter.

## Interface Principles

- Use cards for grouped information.
- Use tables for operational lists.
- Use right-side panels for detail views.
- Use timeline sections for audit context.
- Use metric cards for dashboard summaries.
- Keep actions visible but not noisy.

## Navigation Rule

The main product navigation should remain consistent across modules.

Core routes:

- Dashboard
- CRM
- Transactions
- Operations
- Finance
- Knowledge
- Copilot
- Notifications
- Workflows
- Object Explorer

## UI Rule

A user should always understand:

- Where they are.
- What object they are viewing.
- What needs attention.
- What action is available.
- What changed recently.
