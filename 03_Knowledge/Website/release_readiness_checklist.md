# Release Readiness Checklist

A page may not be marked Production Released until all gates pass.

## Gates

1. Content QA
2. Component integrity
3. Visual consistency
4. Responsive layout
5. Squarespace/export compatibility where applicable
6. Accessibility
7. SEO
8. Release audit
9. Continuity Package update

## Evidence Rule

Each release must include a repository audit listing files added, modified, archived, and deleted.
