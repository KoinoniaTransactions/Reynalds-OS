# Koinonia Website Production Framework

## Status

Draft

## Purpose

This document defines the production standards for the Koinonia public website.

It serves as the bridge between:

- Business Objects
- Brand Standards
- Website Specifications
- React Components
- Production Implementation

Every public page must conform to this framework.

---

# 1. Website Mission

The Koinonia website exists to:

- Clearly explain Koinonia's services.
- Build trust with Realtors and Brokerages.
- Demonstrate operational excellence.
- Generate qualified consultations.
- Reflect the professionalism of the Koinonia brand.

---

# 2. Canonical Source Hierarchy

Content must be created in this order:

1. Business Objects
2. Brand Core
3. Website Specifications
4. Recovery Snapshots
5. React Components

Never invent content without checking higher-level sources first.

---

# 3. Brand Personality

The website should feel:

- Professional
- Executive
- Organized
- Calm
- Premium
- Helpful
- Trustworthy

Avoid hype, clutter, and unnecessary complexity.

---

# 4. Editorial Standards

Write for busy real estate professionals.

Content should be:

- Clear
- Direct
- Helpful
- Easy to scan
- Professional

Avoid jargon where possible.

---

# 5. Design Standards

Every page should include:

- Hero
- Supporting sections
- Strong visual hierarchy
- Consistent spacing
- Clear CTA
- Footer

---

# 6. Component Standards

Approved reusable components:

- Hero
- TrustPillars
- UniversalCard
- FAQ
- CTA
- Footer

---

# 7. SEO Standards

Every page should include:

- One H1
- Logical H2 hierarchy
- Meta title
- Meta description
- Internal links
- Canonical URL

---

# 8. Accessibility Standards

Pages should support:

- Semantic headings
- Keyboard navigation
- Descriptive links
- Accessible contrast
- Image alt text

---

# 9. Image Standards

Images should be:

- Professional
- Consistent
- Executive
- Brand aligned

Avoid generic stock photography whenever possible.

---

# 10. Production Checklist

Before a page is complete:

✓ Business Objects verified

✓ Brand verified

✓ Specifications verified

✓ Mobile reviewed

✓ SEO reviewed

✓ Accessibility reviewed

✓ Components approved

✓ Git committed

✓ website_status.md updated
