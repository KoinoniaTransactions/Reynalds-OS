# Home Page Assembly Audit

## Status

Planned. Not yet executed against repository files.

## Purpose

Audit the current Home page implementation and assemble it from approved components where possible.

## Required Questions

1. Does a canonical Home page implementation exist in the repository?
2. Which components does it already use?
3. Which components can be reused from the approved catalog?
4. Which content is genuinely unique to Home?
5. What must be changed before launch?

## Expected Assembly

- Hero
- Value proposition / positioning section
- Trust or proof section
- Services preview using card component
- CTA
- Footer

## Home Page Goal

Within 10 seconds, visitors should understand:

1. What Koinonia is.
2. Why it matters to Realtors.
3. What to do next.

## Rule

Do not redesign Home from scratch until reuse/refinement has been attempted.
